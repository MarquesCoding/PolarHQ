# @polarhq/desktop — Vault desktop (Tauri 2)

A thin Tauri 2 shell around the same Vite frontend the web app builds
(`apps/web`). In dev it loads the Vite dev server (`http://localhost:3000`); in a
release build it bundles `apps/web/dist`. Bundle identifier: `vault.polarhq.app`.

> **Status: scaffolded, not yet built.** The Rust toolchain is required to compile
> a Tauri app and was not available in the environment where this was scaffolded,
> so the Rust side has **not been compiled or run**. Follow the steps below to
> build it; expect to iterate on the Rust/`tauri.conf.json` if anything is off.

## Prerequisites

- **Rust** (stable) via [rustup](https://rustup.rs): `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
- Platform deps per the [Tauri 2 prerequisites](https://tauri.app/start/prerequisites/)
  (Xcode CLT on macOS; WebView2 on Windows; webkit2gtk on Linux).

## First-time setup

```sh
pnpm install                       # links @tauri-apps/* (the JS side)
# Generate the icon set from the Vault logo (creates src-tauri/icons/*):
pnpm --filter @polarhq/desktop tauri icon ../web/public/favicon.png
```

## Develop / build

```sh
pnpm --filter @polarhq/desktop dev     # runs `pnpm --filter web dev` + the native shell
pnpm --filter @polarhq/desktop build   # builds apps/web then bundles the app
```

## Window chrome

The window is **frameless** (`decorations: false`) with the macOS title-bar style
set to `Overlay` and the traffic lights positioned into the sidebar
(`trafficLightPosition: { x: 16, y: 22 }`, requires `macOSPrivateApi`). To make the
window draggable and keep the traffic lights from colliding with the brand, the
sidebar header in `@polarhq/interface` (`FlatSidebar`) should, when running inside
Tauri, get a `data-tauri-drag-region` attribute and a little extra left padding —
wire that off a runtime `"__TAURI_INTERNALS__" in window` check.

## Layout

```
apps/desktop/
  package.json            # @polarhq/desktop — JS deps + tauri scripts
  src-tauri/
    Cargo.toml            # vault-desktop crate
    tauri.conf.json       # window + build config (devUrl :3000, dist ../../web/dist)
    build.rs
    src/{main,lib}.rs     # the Tauri builder
    capabilities/default.json
    icons/                # generated by `tauri icon` (gitignored output kept minimal)
```
